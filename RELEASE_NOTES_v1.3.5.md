# DentaFlow v1.3.5

Version corrective de la [v1.3.4](../../releases/tag/v1.3.4), dont elle reprend toutes les nouveautés. Mise à jour recommandée si vous utilisez le **kiosque patient**.

## 🛠️ Corrections

- **Écran « Demandes » : le bouton « Actualiser » était coupé** sur les écrans les moins larges. La barre de saisie passe désormais à la ligne au lieu de tronquer le dernier bouton.
- **Assistance à distance** : nouvelle option de démarrage `--donnees <dossier>` permettant de lancer le logiciel sur un jeu de données séparé, sans toucher à la base du cabinet.

## 📥 Installation

Téléchargez **`DentaFlow-Setup.exe`** ci-dessous et double-cliquez. L'installation remplace la version précédente et **conserve toutes vos données**.

Fermez DentaFlow avant d'installer : Windows ne peut pas remplacer un programme en cours d'exécution.

Windows 10 / 11 (64 bits) · ~60 Mo · .NET inclus.

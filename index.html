Multi-postes

Un seul code pour tout le cabinet

Vous activez un seul code sur le PC principal. Les autres postes du cabinet se connectent tout seuls, sans code, et partagent les mêmes dossiers patients en temps réel.

  1. Activez le PC principalCollez votre code d'activation : ce poste devient le « pilote » du cabinet.
  2. Partagez le dossier de donnéesDans Paramètres, choisissez un dossier et partagez-le sur votre réseau.
  3. Les autres postes rejoignentUn clic sur « Rejoindre le cabinet » : aucun code à saisir, aucune configuration.
